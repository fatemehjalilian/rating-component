# Frontend Mentor - Interactive rating component solution

### The challenge

Users are able to:

- View the optimal layout for the app depending on their device's screen size
- See hover states for all interactive elements on the page
- Select and submit a number rating
- See the "Thank you" card state after submitting a rating


### Built with

- Semantic HTML5 markup
- CSS custom properties
- JavaScript
- Flexbox
- Mobile-first workflow


### Features

- Select a rating from 1 to 5 
- Submit the selected rating
- Display a personalized thank-you message with the selected rating
- Interactive hover, focus, checked, and active stated
- Keyboard accessible rating selection 
- Responsive layout for different screen sizes 
- Accessible form structure using semantic HTML
- Native form validation for required rating selection
- Smooth trasitions for interactive elements

- index.html
- style.css
- main.js
- README.md
- assets/
